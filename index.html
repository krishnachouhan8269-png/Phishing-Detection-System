ABOUT THE PROJECT

Understanding and identifying suspicious website URLs.

PROJECT OVERVIEW

Phishing Detection System is a web-based project that analyzes URL characteristics using predefined security rules. It assigns a risk score based on selected indicators such as missing HTTPS, IP-based domains, suspicious URL structure and URL length. It helps users understand potential URL risks.

SYSTEM FEATURES

Key capabilities of our detection system.

01 / URL ANALYSIS

Analyzes URL structure and selected characteristics.

02 / RISK SCORING

Calculates a risk score using predefined rules.

03 / HTTPS CHECK

Checks whether the URL uses HTTPS.

04 / IP DETECTION

Identifies URLs that use an IP address as the hostname.
